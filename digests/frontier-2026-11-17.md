- **[Where Language Models Fail Like Aphasic Patients and Where They Don't](https://arxiv.org/abs/2611.18591)** · 2026-11-17
  Uses known VLM architectural properties to derive falsifiable predictions about failure modes, an interpretability-driven evaluation method rather than a black-box benchmark.
- **[The Judge Is Not Impartial: Self-Preference in Medical LLM Evaluation](https://arxiv.org/abs/2611.18616)** · 2026-11-17
  Quantifies self-preference bias in LLM-as-judge setups for medical QA, directly relevant to LLM evaluation methodology and judge reliability.
- **[Evaluating the Robustness of Fact-Checking LLMs on Multilingual Evidence](https://arxiv.org/abs/2611.18623)** · 2026-11-17
  Extends EuroVerdict to test fact-checking LLM robustness under multilingual/incomplete evidence, a reusable benchmark methodology for evaluation robustness.

  Introduces StaleBench, a benchmark isolating stale-fact retrieval failures in agent memory systems with 892 real updating facts, directly useful for evaluating agentic LLM retrieval correctness.

  Proposes calibrated LLM-judge protocols and identifies Goodhart traps when using speech grounding to reduce 'AI flavor' in generated text, relevant to LLM-as-judge evaluation reliability.
- **[Risk-certified prompt optimization for LLM-as-a-judge guardrails](https://arxiv.org/abs/2611.20156)** · 2026-11-17
  Frames LLM-as-judge guardrail prompt selection as a constrained optimization with statistical risk certification, a concrete method for building more reliable judge/guardrail systems relevant to reward hacking mitigation.
- **[Abstention Direction in Large Language Models: Mechanistic Interpretability of Abstention Across Query Ambiguity, Knowledge Limits, and Safety Alignment](https://arxiv.org/abs/2611.20441)** · 2026-11-17
  Mechanistic interpretability work isolating distinct internal 'abstention directions' for query ambiguity, knowledge limits, and safety alignment, extending prior refusal-direction research.
- **[GPRM: Global Perspective Process Reward Model](https://arxiv.org/abs/2611.20755)** · 2026-11-17
  Proposes a new process reward model architecture with improved historical/global context modeling for step-level reasoning evaluation, directly relevant to RL reward design and reward hacking mitigation.
- **[Edit Recommendation: Can LLMs Anticipate Edit Requests from Users, and When?](https://arxiv.org/abs/2611.21155)** · 2026-11-17
  Introduces EditRecBench, a new benchmark testing whether LLMs can anticipate user edit requests before they're made, a concrete human-AI interaction evaluation method.
- **[MemeEconomy: Do LLM Agents Trade Ethics for Survival?](https://arxiv.org/abs/2611.18908)** · 2026-11-17
  Introduces a simulated economic-survival scenario testing whether aligned LLM agents abandon ethical compliance under pressure, directly probing reward hacking and alignment failure modes.

- **[HEAMS: Holistic Evaluation of Agent Memory Systems](https://arxiv.org/abs/2611.20144)** · 2026-11-17

- **[DetourBench: Trajectory-Level Evaluation of Interactive Agents with Exact Minimum-Action Bounds](https://arxiv.org/abs/2611.20844)** · 2026-11-17

  Proposes a validation protocol for probabilistic safety judges used as RL reward signals, directly addressing reward-hacking blind spots in RLHF-style training.

  Introduces a benchmark for testing whether LLM judges can correctly identify culturally inappropriate content, relevant to LLM-as-judge evaluation reliability.
